## DC6 是个什么机房？

DC6 的后台编号是 USCA_6，官方名称 CN2 GIA ECOMMERCE，简称 CN2 GIA-E，2019 年上线，托管在洛杉矶 DRT 机房。到中国大陆的线路由 ZenLayer 提供，属于双程 CN2 GIA，去程回程都走电信精品网，联通和移动方向用的是中国电信提供的企业级链路。

官方对它的描述有三条：中国电信 CN2 GIA；对中国移动、中国联通使用电信提供的 2.5Gbps 企业级传输；其他地区走 2.5Gbps 电子商务优化网络。带宽 2.5Gbps 起步，套餐越贵口子越大，最高到 10Gbps。"ECOMMERCE"这个命名也点明了定位：外贸建站这类对带宽和稳定性都有要求的场景，本来就是它的目标用户。

和它对应的是 DC9（USCA_9）：同样是三网 CN2 GIA，但线路是搬瓦工直接向中国电信购买的，托管在洛杉矶 Coresite 机房，带宽固定 1Gbps。现在这两个机房都只能通过 CN2 GIA-E 套餐使用。
